# Prototype Mode QA

## Known-Failure Regression Fixture

Use this prompt to verify Prototype mode no longer produces an HTML presentation for component redesign work:

```text
Give me 4 topbar redesign directions for this chat page.
Use the actual rendered page context and keep each option in the page where the topbar lives.
```

Expected artifact structure:

```text
.dynamo/prototypes/<slug>/
  prototype.json
  index.html
  .reference/
    dom.html
    computed-styles.css
    meta.json
    screenshot.png
  assets/
    tokens.css
    prototype-viewer.css
    prototype-viewer.js
  frames/
    option-a.html
    option-b.html
    option-c.html
    option-d.html
```

Expected behavior:

- Provider logs show `DYNAMO_DESIGN_EXTRACT` or `dynamo-design-extract`.
- If a topbar selector is known, the extractor command includes `--selector`.
- `.reference/meta.json` includes `layoutRegions`; it includes `target` when a selector was supplied.
- `prototype.json` uses `version: 1` and `mode: "page-canvas"`.
- `index.html` is generated by `DYNAMO_PROTOTYPE_VIEWER` or `dynamo-prototype-viewer`.
- Each `frames/option-*.html` is a page-context frame with surrounding app chrome.
- Option labels appear in viewer chrome, not as page hero content.
- The output does not read like a slide deck, marketing page, or design-rationale document.

## Manual Viewer QA

Open `.dynamo/prototypes/<slug>/index.html` in an external browser.

Check:

- Pan by dragging the canvas.
- Zoom with toolbar buttons and wheel or trackpad.
- `0` resets the canvas.
- `+` and `-` zoom.
- Arrow keys pan.
- Fit places all frames in view.
- Direct-open links open individual `frames/*.html`.
- Reload restores a meaningful canvas transform from the URL hash.
- Six 1440px frames render without collapsing or overlapping viewer chrome.
- Single-frame prototypes still open through the viewer and directly from `frames/<id>.html`.

## Troubleshooting

- Missing `.reference/`: confirm the prompt referenced an existing rendered screen and that the provider ran the app-owned extractor.
- `Script not found "dynamo-design-extract"`: restart `dev:desktop` so provider sessions inherit `DYNAMO_DESIGN_EXTRACT`.
- Missing `index.html` viewer chrome: confirm the provider ran `DYNAMO_PROTOTYPE_VIEWER` after writing `prototype.json`.
- Browser blocks `prototype.json` fetch from `file://`: regenerate the viewer; the app-owned viewer embeds manifest JSON into `index.html`.
